# THE GALLERY WAS THE EXCEPTION IN THIS SENTENCE UNTIL 2026-09-06, AND IT WAS NOT ONE. It is
# the kit sheet, so nothing on it fetches DATA — but `Gallery.tsx`'s `CardLocations` specimens

# port in `app/tests/shell.ts`, which stubs both for the specs; nothing stubs anything here,
# so this line is a warning rather than a fix.
