# This file is an INPUT and is tracked. It used to live at captures/views.txt, inside the
# directory .gitignore excludes wholesale — so the list of which views are worth looking at

# The URLs assume `make dev` is already serving. It blocks, so background it first.

# WHAT THESE RENDERS SHOW DEPENDS ON WHETHER `make server` IS UP, and that is worth knowing
# before comparing one against docs/design-refs/locked.html. Every view below except the
# gallery reads the capture server: with it down they draw their failure panel, which is a
# real screen and the wrong one to judge a layout by. With it up and an empty store they draw
# their empty state. Neither shows a populated screen, and no run in this repo has ever
# produced one — see docs/specs/capture-app.md's STATUS section.

# The hash route is load-bearing, not decoration. The gallery answered at '/' while it was
# the whole app at step 6; step 7a mounted the capture screen there. Dropping the '#/gallery'
# renders the capture screen into captures/ui/pull-confirm.png — a screenshot that is named
# after one view and shows another, which is worse than no screenshot, because the loop
# docs/DESIGN.md calls mandatory is a human comparing this render against the reference.
pull-confirm  http://localhost:5173/#/gallery
