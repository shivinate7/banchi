# Paths the docs name before they exist. One `path  # reason` per line.
#
# SELF-CLEANING: scripts/docs-audit.py FAILS when a path listed here exists, so the entry
# has to be deleted at the moment it stops being true. An allowlist that only grows turns
# into a list of things nobody has looked at since — the same reason scripts/stop-gate.sh
# arms itself on the absence of NOT_IMPLEMENTED markers instead of on a toggle.
#
# A reason is not optional. "Build-order step 6 creates this" is a reason; the path
# repeated back in prose is not. If the reason is that the audit misread ordinary prose as
# a path, the fix is the path extractor's own rules, NOT a line here.
#
# Only paths under an existing top-level directory ever reach this file. Anything else —
# `PokemonTCG/pokemon-tcg-data`, `sets/en.json`, `claude.ai/code` — is somebody else's
# namespace and is never checked in the first place.
#
# An ALL_CAPS entry is an identifier rather than a path — an env var, or a test id a doc
# names in order to say it does not exist. It goes stale when the code starts referencing
# it, which is the moment the thing became real.
