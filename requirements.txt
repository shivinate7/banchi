# Harness + pipeline runtime. Installed into .venv by `make venv`.

# anthropic  T1's identification transport (Batch API). Nothing else in the repo
#            talks to Anthropic — see identify/batch.py.
anthropic>=0.69

# Pillow  image handling for `pkmnscan identify`: the 1568px downscale (anything
#         larger is billed and then discarded by the API) and the crop-retry bands.
#         Not optional — there is no stdlib path to either.
# numpy   the array maths behind geometry/: thresholding, projection profiles, the
#         coarse rotation search. Pure compute, no system libraries.
#
# Both are a recorded decision, not a drive-by import — batch script v2 spec §4.5.
# `opencv-python-headless` is the named fallback IF measured detection rates are poor.
# They were measured on 2026-08-22: the tone path found the card in 0 of the 53 Gate B
# photographs. The fallback was still not taken, because opencv would not have helped —
# that path failed on a false premise (a background flat relative to the card's own
# contrast), not for want of a better segmentation library. What answered was a
# different question, the border search in geometry/detect.py, and it needed no new
# dependency: it is more of the numpy already listed above, 53/53. The 40 MB binary
# stays absent, now against a measurement rather than against the absence of one.
# §4.5 carries the mechanism.
Pillow>=9
numpy>=1.21

# zxing-cpp  the code-card track's QR decoder (codes/qr.py). The redemption code IS the
#            QR's payload, so this is what makes the primary path for `pokemon_code`
#            deterministic, local and free — no model call for the one field that must be
#            exactly right, because it is the thing being sold.
#
# THE PIN IS LOAD-BEARING AND `>=` WOULD BREAK A CLEAN CLONE. This venv is Python 3.9.6
# (`/usr/bin/python3` on this machine). The 3.x line dropped cp39 wheels, so plain
# `pip install zxing-cpp` resolves 3.1.1 — whose `requires_python` is still >=3.9 — finds
# no wheel, falls back to the sdist and DIES in CMake configure. It does not quietly pick
# an older release. 2.3.0 ships a real cp39 universal2 wheel, 1.7 MB, no dependencies.
# Revisit the pin only alongside a Python upgrade, and re-measure codes/qr.py if you do:
# 3.1.x claims a materially better Version-1 detection rate, which is exactly the symbol
# size a 1 cm code produces.
zxing-cpp==2.3.0
