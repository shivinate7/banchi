# Banchi: where the rules are

This file is a pointer. It holds no rules.

1. Read the shared rules first: `CLAUDE.md` in the `shivinate7/claude-settings` repository
   (`~/claude-settings/CLAUDE.md` on a machine that has it).
2. Then read this repository's `CLAUDE.md` for what is specific to Banchi.

**claude-settings overrules this repository.** When the two disagree, claude-settings wins, unless this
repository's `CLAUDE.md` or a decision in `docs/decisions/` names the exception and says which shared rule
it departs from. A rule here that does not name its exception does not override a shared rule.
