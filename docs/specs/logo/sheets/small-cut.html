the small optical cut — the sweep

Section 3 asserts a small cut of stroke 3.4, no taper below 64px and nothing has ever drawn it. That value is the starting bracket here, not the answer: section 7 rule 2 says open wide enough that both ends are wrong, so the stroke sweep runs 2.4 to 5.0 and is expected to fail at both. Every mark is the locked bluesteel — ground #182430 → #060B12, sheen 0.15, prism bluesteel, chrome brackets, base #5A6E80 — so the only thing moving in each sweep is the one named parameter.

The magnified views are rasterised, not re-drawn. Each mark is rendered to a canvas at its true pixel size and then blown up with nearest-neighbour, so what you are looking at is the actual pixel grid a 1x display gets. Scaling the vector instead would have shown a drawing nobody's screen ever renders — which is how section 9's small row flattered itself: shot at deviceScaleFactor 2, its "28px" tiles carry 56 real pixels.
