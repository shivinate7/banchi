## 8 — Recorded and correctly unfixed

No work proposed. Each item is a gap a green run does not show.

- **Supervisor drain window.** A request accepted but not yet inside `_dispatch` is uncounted by the drain (D138, `scripts/serve.py`). The window is microseconds. Closing it means reimplementing `handle_one_request`.
- **No rollback after a bad restart.** `scripts/serve.py` refuses to restart into a file that does not `compile()`. An `ImportError` or module-scope `NameError` still kills the new child with the last-good process already gone. Containment is the fast-failure cap: after five quick deaths it stops respawning. A rollback needs the socket-passing design D138 rejects for v1.
- **The swap gap.** Between the old child exiting and the new one binding, a request gets `ECONNREFUSED`. `app/src/server.ts` has no retry, so it surfaces as `unreachable`. Tens of milliseconds.
- **The supervisor's build is tested against a stub.** `make serve-selftest` uses a stub `app/` whose build writes one file. The supervisor's contract with the real `vite build` (exit code on a type error, the `dist.next` rename) is asserted by nothing.
- **A runner-only red after Escape.** About one `design-check` job in thirteen fails on the assertion right after `keyboard.press('Escape')` (`capture-claims.spec.ts`, `live-reconcile.spec.ts`, `markdown.spec.ts`). The same sequence passed 555 of 555 times outside the suite, so the suite around it is part of the mechanism. `app/playwright.config.ts` keeps a trace on failure under `CI`, and the first trace should show whether the track is open at the Escape. The workaround is `gh run rerun <id> --failed`. A retry in the spec would hide the mechanism.
- **A starved rig is not a slow one.** At 40 workers on 12 busy cores a context can fail to render and a press can drop, and no wait answers that. `make design-check` runs 7 workers and does not reach it.
- **The `fixtures/` guard is one tool wide at write time.** `.claude/settings.json` denies `Write` and `Edit` under `fixtures/`, and Bash (`cp`, `sed -i`, a script) goes past it. The commit half holds: `scripts/githooks/pre-commit` refuses any staged change under `fixtures/`. The residue is a red `make harness` before any commit.
- **An unwritten history line is visible only to T7.** The three writes that change no state (a correction, a capture undo, a review answer) each leave a history row, asserted by `harness.tests.t7.history_sidecar.check_history`. No route serves the history and no screen shows it, and the vocabulary lives in two places (`master.STATES` and `SERVER_EVENTS`).
- **D60's guards see tokens, never arguments.** `scripts/prose-guard.py` compares hard tokens (backticked identifiers, paths, ids, measurements). A rewrite that keeps every token and loses the reason an entry exists passes.
- **`check dispatch` cannot see its own unwiring.** Delete its entry from `ROWS` and every other row stays green. Only `--self-test` catches it.
- **`design tokens` locks values only for the hexes `docs/DESIGN.md` states.** Some tokens are an alpha of another token, an alias, a duration, an easing curve, a shadow or a height. Each is checked for existence in both directions and for value nowhere. Closing it needs a small CSS color engine that resolves `color-mix()` and `rgba()`.
- **The browser matrix's path scope reads literals.** `scripts/browser-scope.py:SCOPE` is derived from the two configs and the `design-check` recipe. It also reads every string literal in `app/tests` and `app/src` that names a tracked file outside `app/`. A path built from pieces, or a Vite `server.fs.allow` widening spelled through a variable, is invisible. The matrix would then skip a change it should run for, with the row green. Neither exists today.
- **Some guards do not gate a commit.** The commit path runs no product code, so two import-time contracts gate `make harness` and `make check` and not the commit: the `assert` that `UNPRICEABLE_REASONS` is a subset of `ROUTING_REASONS` in `pipeline/routing.py`, and the `RuntimeError` that `CAPTURE_CLAIM_FIELDS` names only `Card` fields in `store/master.py`. A failing `sigil-check.py --self-test` warns and allows at commit (a broken checker is not evidence a screen is wrong), and `make check` blocks on it.
- **One URL per product holds per call, not across calls.** `pipeline/pricehistory.Market`'s `readings_for_rows` stops a product's ranges after a lost one (D319, every network call retries through one method). The next call asks that product again from its first range, with its full retries. Its lost calls count toward the host's degraded run, and any other product's answer resets the run. It heals by itself.
- **Two queue reads still see departed cards.** `cli/requeue.py` walks `Queue.open_entries`, so a retired, sold or moved card can be requeued. `Queue.__len__` counts open entries, not owed ones (UN-8, a departed card owes no answer), and has no caller today. Every count a screen or a run line shows goes through `Queue.owed_entries`.
- **A fresh Market skips the Retry-After gap on its first call.** Each press builds a new Market, and the gap is gated on `self.requests`. The next press can call a host that asked it to wait.
- **`numbered record growth` reads a conflicted merge's staged main files as this branch allocating a number.** A merge of main that needs a hand-resolved conflict commits through the hook, which sees main's numbered decision files in the staged diff and refuses. A clean merge passes. Keep conflicts off shared lines, such as a target's own `.PHONY` line.
- **`net` reads "answered" from a call's last attempt only.** A 503 then two refused connects records as unanswered, so the courtesy delay is skipped although the host answered once.
- **A write that follows a redirect is retried whole on a refused hop.** With `follow_redirects=True`, a write redirected to a closed port is sent again from the start. No write does this today: `server/portal_http.py` sends every TCGplayer write with `follow_redirects=False`. A new write caller must do the same.
- **A Sales photo ask in flight is not aborted when the board changes.** `server.ts`'s `getSkuPhotosSettled` stops its timer on unmount, but a call already sent finishes, and the next mount's asks wait behind it on the one shared line. The server's `photo_busy` 503 bounds the wait.
- **The Sales photo retry timer is outside `usePoll`** (D207, all polling goes through usePoll). It is a plain timer with no hidden-tab pause, so a stuck SKU is asked once per 8 s until Sales closes. It was outside `usePoll` before this change too.

- **The Slabs focus hand-over can take focus from the Add sheet.** After Remove, `Slabs.tsx` moves focus to the next Card button when the list read lands, if focus sits in any overlay. If the person opens Add a Slab and types before a slow read lands, focus jumps to Close and the next keys are lost. It needs a read slower than the person, which is rare on loopback. The fix is to check the detail sheet only, or to let the kit `Sheet` take a return target (`useReturnFocus` already accepts one).
- **The kit `SkeletonText` shimmer runs left of the page edge.** Seen on the Slabs loading count line: at 1440 it starts left of the page inset, and at 820 it runs over the rail. The cause is in the kit, not the screen.
- **The kit refusal toast shows the server's text as its body.** A Slabs Undo refused with `store_busy` or `store_unavailable` would show a pipeline noun or a file name in the body. Slabs follows the kit. Each screen that calls `refusalToast` with those codes has the same gap.
- **Slabs Worth copy repeats a fact.** The Worth source lines restate their labels, and a no-sales slab says it has no sale under Worth and again under Sales. Wording only.

- **Two screens mark their "Unnamed Box" fallback as a typed value.** `Fulfillment.tsx` and `BoxOps.tsx` put the fallback inside `data-typed`, so the copy-casing sweep never grades it. Slabs marks only the stored name (`Slabs.tsx` `NameText`), which is the pattern to copy.
- **The Slabs sheet title's typed marker is unasserted.** `slabs.spec.ts` checks the marker on the Card button only. The sweep never opens a sheet, so a marker moved onto the sheet title's whole heading would pass.
- **The Slabs Undo reason repeats the toast body.** For a sign-in refusal it matches word for word, and nearly so for the daily limit and for an add still running. Hovering adds nothing there.
- **A Slabs reason tip closed with Escape comes back.** It returns when the mouse leaves the trigger while keyboard focus stays on it.
- **Two Slabs cases have no test.** One is a tip opened by hover and closed with Escape. The other is a refused-Undo toast over an open detail sheet.
- **A hot reload of `Slabs.tsx` leaves one inert listener.** In development, one window Escape listener stays behind. It does nothing.

- **PR #906's "settled" count overclaims a card with no market data.** The summary helper in `cli/cmd_identify.py` (`_held_now`) counts a card with no open queue entry as settled, and a card with no market data can be one.
- **The "Join again" button wording is unsettled.** Every run now joins itself (D321, every identify run joins itself at its end), so a press repeats a join and does not start the first one.
- **`harness/tests/t7_box_map.py:check_merge_speed` has a 10 s wall-clock backstop that flakes under load.** DEBT43 (the merge-speed guard counts SQLite ticks only) names the backstop. On a loaded machine it fails with no defect in the code.
