After the window, runs 3214 and 3258 were red the same way. Both are nightly (schedule) runs, and both ratios sit near 1.5. The push runs on the same heads passed design-check. That is a pattern to read, not a cause. Run 3214's attempt 2 passed on the same head. A pass on a rerun does not clear the first red.

The logs show the same drift on a loaded shard: the timed-out run measured a first-10 median of 4400 ms. Not reproduced. Not read: the load on the runner at the time, nor the load in runs 3214 and 3258.
