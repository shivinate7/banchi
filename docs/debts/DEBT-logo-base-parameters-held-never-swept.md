## DEBT-logo-base-parameters-held-never-swept — the mark's four HELD base parameters were never compared

**Gap.** `docs/specs/logo.md` section 3 tags four parameters HELD: the chrome gradient colors, the turbulence base frequency, the turbulence octaves and the card base fill `#5A6E80`. They were chosen once and never put against an alternative. The card base fill was seen beside three alternatives on a light ground, and that sweep was about the ground, so it does not count.

**Cost.** A HELD value is the risk in that file. Of the four HELD values swept in the past, three turned out wrong. The card base fill is the only color in the mark that nothing else constrains. The marbling parameters matter only at the display cut, because the small cut carries no filter.

**Why unfixed.** Every surface in the app draws the small cut or the lockup, so no shipped screen shows the display cut's foil. A sweep needs the owner's eye, by the method in section 7 of the spec. It has no owner today.

**What would close it.** A forced-choice sweep of each value at its true display size, with the incumbent absent from the last row. Or a decision that the display cut is not worth the sweep, with the four values re-tagged LOCKED by argument.
