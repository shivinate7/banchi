## DEBT-catalog-number-crosscheck — the collector number is not cross-checked against the local catalog

**Gap.** With a set hint, the catalog yields `(set, name) -> number` and `(set) -> printedTotal` independently of the model. Agreement is confidence and disagreement is a review reason. It catches a right name with wrong digits. The model's digits catch a wrong name with the right number.

**Limit.** It converts misses into review taps and buys safety, not a higher T1 score.
