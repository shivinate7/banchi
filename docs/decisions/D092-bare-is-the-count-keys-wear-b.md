# D92 — Bare # is the count; keys wear B

**A bare `#` on an owner-side screen shows D58's count of the cards in a box, never the store key.** A key appears only with the `B<box>` sigil (D68). A departed card has no count, so it shows `B3 #27`. `slot` is what a renderer draws. `index` is what a caller addresses. `_company` sends both for each neighbor. `PlaceNeighbor.index` is sent unread, for click targets (D45).

- **A frozen count for a departed card was rejected.** 104 of 105 departed records carry a number that a live card in the same box holds. A live card is the one somebody walks to. A frozen count is a fact, never an identifier. Drawing it in the card panel is not built. It needs the event log.
- **`scripts/sigil-check.py` refuses a `#` composed from an expression that names `index`, on the commit path.** It is narrow by design. It cannot tell a count from a key in general. Its real value is the renders nobody asked about. A legitimate site carries a `sigil-ok:` marker with its reason. The check reads text, so a renamed local or a helper gets past it (DEBT9). The undo filmstrip's `slotNumber` helper fell back to the raw index, and drew a key with the count's sigil. The spelling of a key lives in `app/src/storeKey.ts` (`STORE_KEY`). So the reader and the writer of one string share one file (D67).
- **A rendering that nobody can correct is joined at read time and never stored** (D56). The stored `entry.label` writes are gone. A comment that states the opposite of the rule is worse than no comment.
- **The slot column belongs to the list.** A row cannot see whether its siblings drew a key. Its terms split by provenance. Typography may be a measured constant: `--pos-slot-key` is 37.594px in `px`, measured on the real screen, because `rem` overflowed at a 12px root. Data may not be a measured constant. The figure's width is spent in the figure's own `ch`, from the count `src/CardLocations.tsx` reads off `place.card`. A box holds 999 cards. `.position-slot` is `max-content`.
- **A `ch` reservation that matches another element's must match the whole face,** family and weight. Manrope's `1ch` is 14.828px at weight 800 and 13.772px at 400. `.position-void` carries the figure's face and paints its dash through `::before`. `box-sizing: content-box` keeps the key's padding additive.
- **Element-box measurement cannot see glyph overflow.** The figure flex-shrinks to one width while its glyphs paint outside it. The case reads `scrollWidth` and a `Range` over the text node.
