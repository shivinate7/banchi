## D152 — Rail rows share one glyph spine

**Every row in the collapsed 64px rail draws one glyph on one spine at x = 32 (the 8px gutter plus half of the 48px box each row draws in).** A rule that lists the children it knows about will miss one. `App.css`'s rail block folded the foot away by enumerating class names (`.bn-nav-text`, `.bn-kbd`, `.bn-nav-badge`, `.bn-side-foot-text`, `.bn-brand-chevron`), so the Fulfiller link's 14px `external` mark stayed and the row drew glyphs at x = 19 and 47. Anything the list does not name silently keeps its open-sidebar layout. `.bn-btn`'s structural rule (`> :not(.bn-icon)`) never had the defect. The fix is that shape: `.bn-nav-link > :not(:first-child)` keeps the leading glyph and nothing else.

- **The width is fixed and the centring resolves against it.** `justify-content: center` against the sidebar's width resolves against a box that animates for 320ms. A 48px box pinned at the gutter does not travel, so every foot row rests on 32 from the first frame.
- **The block exists twice.** The shell is railed by `data-rail` above 1023px, and by a media query at 768 to 1023px with no `data-rail`, which deliberately copies the block. A fix or a test that looks only at 1440 covers half.
- **The guard is the resting position.** `brand.spec.ts` asserts travel through the collapse, which is blind to a glyph whose resting position is wrong. `every foot row in the rail draws one glyph, on the nav's own spine` asserts one visible glyph per foot row within 1px of the nav icons above it, at 1440 and at 820. The spine is read from the nav and not typed, so it cannot go stale when the rail is resized. A test over the nav's rows is not asserted, because no row draws a second glyph and a test over an empty set is the failure this repo keeps finding. The phone drawer (below 767px) draws every label on purpose and is not covered.
- **The sidebar's server-status dot is deleted** from the rail, the sidebar and the phone drawer. The offline banner (`role="alert"`, with Retry) already says when the server is down. The foot is Pull, Go to and Theme.
