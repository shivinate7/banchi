## D54 — Re-emit adds, never subtracts

**`emit` never opens an import file for writing until it has at least one row for it.** What it writes is always the delta, the copies not already sent, and it says so. A second `emit` once overwrote the good `import-listed.csv` with a header-only file and blanked `manifest["emitted"]`. `reconcile` then refused a run that had emitted perfectly.

- **The row set is exact by construction.** `cli/cmd_emit.py:_game_only` intersects `prices_for`'s output with the matches whose `add_to_quantity` is above zero, so `only` equals what `import_rows` will produce. Three things drop a SKU after pricing: a withheld SKU (D86), a `no_market_data` SKU answered `"unlisted"`, and `add_to_quantity == 0`, which is every SKU on a re-emit. Fixing only the last would leave the second standing. `pipeline/join.py:write_import` is split out of `emit_import` so rows are looked at before a file handle opens.
- **Rewriting the file identically is refused.** It would re-count copies already committed, as a Gate B re-emit once did with 37 copies. Import to Staged adds quantity, so repeated rows double-stage, and nothing here knows whether the operator imported the first file (`reconcile`'s job, D34).
- **No refusal, exit 0.** Re-emit is free and re-runnable, and a failure would draw for a healthy run. The no-op says every matched copy is already at `pushed`, that the file is unchanged, and that a price changed after an emit cannot travel this road. It prints no `next: import`.
- **`emitted` is a union across emits,** through `Run.record_emit`. `Run.set` stays replace-not-merge. `reconcile` reports rows in both directions, so a record holding only the last delta reports earlier SKUs as "something else wrote it". `pushed` sums, and `pushed_skus` is derived from the lists so it cannot disagree. A SKU withheld after it was emitted stays. `_phase` asks `Run.emitted_skus`, because a blanked `{"listed": [], ...}` dict is truthy.
- **The guard asserts byte equality of the file across two emits.** A row count of zero is met identically by correct omission and by destruction. It also asserts the manifest after a second emit and the whole cycle `emit`, `join`, `emit`, `reconcile`. Nothing had ever asserted the manifest.

Reopen if `reconcile` can read a fresh Export From Staged and set counts absolutely. Then `emit` could compute the true delta.
