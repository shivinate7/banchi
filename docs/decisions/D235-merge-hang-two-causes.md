## D235 — The merge heartbeat is never piped

**A pipe hides the heartbeat, so guard clause 9 refuses it, and a wait that can no longer succeed stops.** `make merge` looked hung twice when it was correct: `check.yml` takes four to five minutes, and five to ten minutes of waiting is the job working. `CHECK_DEADLINE_SECONDS = 45 * 60`, `CHECK_HEARTBEAT_SECONDS = 60` and `CHECK_POLL_SECONDS = 10` are unchanged, a red run still refuses, and absence is still never a pass (D148).

- **Cause 1: the heartbeat never reached the screen.** Sessions type `make merge ARGS="<n> --confirm" 2>&1 | tail -18`. Python block-buffers a stdout that is a pipe, so mid-run the pipe delivered 0 bytes, and `tail -2` kept 2 of 5 lines. Narrated waiting was indistinguishable from a hang. "Never discard output" stopped nobody, because a pipe into `tail` does not read as discarding (D179).
- **Clause 9 is `PKMNSCAN_NARRATE`.** It refuses a long, heartbeat-emitting command whose stdout is lost: discarded to `/dev/null` or a closed descriptor, redirected to a file nothing in the same command reads back, or piped into `tail` or `head`. The line is loss and never delay. `| tee <file>` and `> <file>` followed by a read of it buffer the heartbeat too, but lose no byte, so they pass. Refusing the careful spelling teaches a session to reach for the hatch. It differs from `silent-write-guard.py` (does evidence survive versus does a stream arrive).
- **It names its subjects instead of resolving them, alone among the nine.** No reader can say before a command runs whether it blocks while narrating. A general clause over every truncating pipe would fire on `git log | tail` and a dozen honest lines a day, and a guard that goes red when nothing is wrong is spent. So the roster is short, one entry per incident. A preview never waits, so `make merge ARGS=<n>` without `--confirm` is never its business (the carve-out has its own mutation arm). The self-test asserts every named command still carries a heartbeat constant in the file that runs it. `make design-check` is deliberately absent, since it backgrounds itself and writes `.serve/design-check.json`. The remedy never names the forbidden target: it says to run the command with nothing after it and how long the wait legitimately takes.
- **Cause 2: the wait could not see the branch stop being mergeable.** When another session merges first, the waiting branch can go `DIRTY` while its own claim commit's checks keep passing, and the wait sat for the full 45 minutes on a merge that could not succeed. `mergeable_half` asks once before the claim, and D228 says a gate there does not close the race. `wait_for_checks` takes an optional `mergeability` reader and asks at most once per `MERGEABILITY_RECHECK_SECONDS` (60s, six times the check poll, since each is a `gh pr view` against a rate limit). It is not a second mechanism. A conflict returns NOT GREEN, the path `claim_half` already has, so `rollback_claim` backs the claim out as for a red check (D228). `UNKNOWN` is never read as conflicted: GitHub answers it routinely while it computes, and only the literal `CONFLICTING` ends the wait. An unreadable answer, a failed `gh`, non-JSON and a reader that raised are no news, and the wait continues on the checks (D148).
- **Proof.** `make guard-shell-selftest` performs the incident in the fixture over a real narrator and a real `tail`, then the refusal cases, the must-never-refuse cases, both hatch forms and the roster reconciliation. `scripts/claim-selftest.py` covers CONFLICTING ending the wait, `UNKNOWN`, unreadable answers and a throwing reader never doing so (each asserting the reader was really asked), and the recheck interval against the shipped constants. `make mutate-anchors` and `scripts/mutate-guards.py` cover clause 9 and the wait, and `scripts/merge-pr.py` is a sixth guard with `claim-selftest.py` as its suite (its fixture mirrors `server/ports.py`, or a mutant dies of `ModuleNotFoundError` and reads as caught). Two guards must not contradict: `silent-write-guard.py` told a session to pipe a refused `make merge` into `tail`, which clause 9 refuses, so that advice is conditional on the verb. An arm passed for the wrong reason until fixed: a roster whose checks went green in two fake-clock seconds never asked the mergeability reader at all. A guard must see its subject.
