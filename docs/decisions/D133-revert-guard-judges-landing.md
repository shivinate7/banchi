## D133 — Revert guard judges what a branch lands

**A branch is judged by what it would land on main, not by its own commits.** A file put back to main's state is refused unless a commit on the branch names it. A keep-ours merge has its merge-base after the commit it reverses, so `origin/main..HEAD` shows a tidy change and only the landing diff shows the revert. `scripts/revert-audit.py branch` diffs origin/main against `git merge-tree --write-tree origin/main HEAD`, which is what the PR page shows and the merge button does. If the merge conflicts it falls back to the branch's diff off the merge-base and says so. A pull-request checkout on GitHub is that merge.

- **Two exact detectors.** *Whole-file:* the change takes a file from blob `a` to `b`. A commit in main's last sixty first-parent commits took it from `b` to `a`, compared by object id. A file deleted that a recent commit created counts, since a keep-ours merge deletes every file main added. *Hunk:* a `-U0` hunk is line for line the reverse of an earlier hunk in that window on the same file. Whitespace-only hunks are dropped. A merge is compared as what it brought onto main, with the branch commits inside it named.
- **Refused means every hunk is such a reversal or the whole file is restored.** A partial reversal beside real edits is a note and never a refusal, or the guard is switched off within the week. **Declared means that a commit message names the file** (path, basename or stem). A meant reversal costs one file name in one message. `BANCHI_REVERT=off` is the escape hatch and is printed in every refusal, as `BANCHI_MAIN=off` is.
- **It runs three times,** for D42's reason that the local and remote halves fail separately: `make revert-guard` in `check` and `ci-check`, `scripts/githooks/pre-push` on every branch push, and its own job in `.github/workflows/check.yml`, so a refusal is a named red check. It writes nothing, and with no `origin/main` in reach it allows and says so.
- **`make revert-selftest` rebuilds the sequence:** A throwaway origin, a deletion merged. A branch merges main with `-s ours` and is squashed under a message naming nothing. It asserts its own arming, the refusal, and the history walk. It also asserts a clean branch, a partial reversal noted, and a declared restoration. It asserts a silent restoration refused at hunk level, the escape hatch, and main landing nothing. It is mutation-tested on three arms.
- **`scripts/revert-audit.py history` is the same engine over main's first-parent line** and reports every reversal whose commit message does not name the file. Read each one to the owner in plain English. A PR number, decision number or file name is not something they can rule on.
- **What it cannot see.** A reversal older than the window (sixty commits is about twelve days, and `--window 0` is for a one-off audit). A reversal re-worded on the way back: it is exact on purpose, since every dial on a gate gets turned until the gate is quiet. A reversal whose hunk a neighboring edit widened: a containment test found 79 coincidences and was not kept, and the whole-file detector answers the common form.
