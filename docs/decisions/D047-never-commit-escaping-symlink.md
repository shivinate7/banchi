## D47 — Never commit a symlink leaving the repo

**A symlink that leaves the repository is destroyed on checkout elsewhere.** Git removes an ignored file or directory that stands in the way of a checkout without asking. A committed link to another Mac's absolute path became a link to itself in the main tree. It replaced the 133 MB eval-image mirror. The error it raised (`FileExistsError` from `mkdir`) named the symptom and not the cause.

- **The pre-commit hook refuses a staged symlink that leaves the repo.** It reads mode `120000` from the index. An absolute target is refused, and a relative one is refused when it climbs out of the tree. A relative link that stays inside is allowed, because only that kind survives a clone (`AGENTS.md` is one). `BANCHI_LINKS=off` bypasses.
- **Ignore patterns for provisioned paths carry no trailing slash** (`node_modules`, `harness/images`, `harness/.cache`, `.venv`). A pattern ending in `/` matches directories only. Git does not count a symlink as a directory. So the link was untracked and one `git add -A` from committing. The rule is about the path, not about today's provisioning script.
- **`make ignore-check` asserts each provisioned path is ignored** as a file, as a directory and as a symlink. It is in `make check` and not in the git hook, because it reads local worktree state. A fresh clone would fail a commit over nothing wrong (D18).
- **The mirror location is asked, never assumed.** `BANCHI_IMAGE_MIRROR` is honored by `harness/eval/fixtures.py`, and its size is why the disk is a choice (D15). `scripts/worktree-guard.sh` and `make worktree-setup` run the main checkout's `fixtures.py`. They link to whatever `IMAGES_DIR` answers, and they say so when no mirror exists. A silent skip was the defect. The path belongs in `.env`, since the Stop hook runs under bash and reads no shell profile. A real environment variable still wins.
- **The docs audit's `ignored_paths` asks `git check-ignore` per candidate,** because one refused pathspec exits 128 and aborts the batch. A batch that did not run cleanly is not evidence about anything. A candidate that walks past a symlink fails even alone. So the function asks its ancestors. Gitignore's directory semantics make an ignored symlink node cover everything beneath it. Its optional `root` lets the self-test use a throwaway repo.

The guard does not stop the links being made. They keep T1 from re-downloading 151 files per worktree. It stops one being committed.
