## D12 — Scope is English Near Mint

**Scope is English, Near Mint, any set in a supported game.** There is no era limit: nothing enforces one, and Riftbound, One Piece and ME01 have run. Vintage and WOTC condition strings (1st Edition, Shadowless, Unlimited) are a spec change, not a parameter. `pipeline/variant.py:CONDITION_BY_FINISH` hardcodes the Near Mint strings, and no set or era filter exists.
