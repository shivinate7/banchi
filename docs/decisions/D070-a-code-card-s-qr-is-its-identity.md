## D70 — A code card's QR is its identity

**The redemption code is the QR's payload, so identification on this track is free.** `codes/qr.py` decodes locally at the rig's 3840x2160 (140 of 140 possible frames, zero mis-reads, 87 ms each). A mis-read sells a stranger something that does not work, and a refusal costs a re-shoot, so the harness asserts zero and never a rate. Three cases are unrecoverable and return nothing: a QR under about 40 px, a 3.5 px defocus, and glare that clips the symbol.

- **The product is a capture claim (D21).** `product` sits on `Card`, in `CAPTURE_CLAIM_FIELDS`, the sidecar and the wire, and `PUT /inventory/<box>/<index>` corrects it. `None` is no claim and is never defaulted, so "the operator said booster" and "nobody was asked" never share a value.
- **The decoder is `zxing-cpp==2.3.0`, pinned.** The venv is Python 3.9.6, and 3.x dropped cp39 wheels. An unpinned install falls back to the sdist and dies in CMake. OpenCV was declined twice. A benchmark at 1600px wide reversed the answer. At the rig's real size, OpenCV scored 72.7% at 211 ms and 0 of 8 on a card filling a quarter of the frame. zxing scored 100% at 67 ms. A benchmark at the wrong input size gives a confident wrong answer.
- **The ledger's key is the code, not the position.** Only a code key can dedupe or hold a reservation. The position survives as an attribute, and the code lands on `number`, so `GET /search` finds it, even on a partial.
- **Only half the pile is destroyed.** Premium code cards are kept, at tracked locations, and shipped. TCGplayer permits codes attached to a physical card and prohibits promo codes that are not. The bulk tier is destroyed. Channels are eBay and TCGplayer, nothing else. `codes/products.py:is_premium` is the tier rule (an ETB code lists at about 46 times a booster).
- **Absorption binds, not price.** At about 30,000 codes the pile exceeds a year of both venues: the bulk SKU absorbs 8,694 units a year against about 19,300 standing, and the premium tier absorbs 924 units and $231 gross a year. `codes/lots.py` guarantees that a code is never committed twice across venues.
- **A physical lot is the whole box or it is refused.** Scoping by count commits 1,000 codes while the operator pulls a different 1,000. The check must ask what is physically in the box, not what is sellable from it. Otherwise it misses an unclaimed code and a code reserved to another lot.
- **TCGplayer's bulk-code SKU is CSV-listable and not worth using.** The photo rule is policy, not mechanism. It is one SKU priced per card with the buyer picking quantity, so the fixed-lot model of `codes/lots.py` fits eBay only. Export Filtered CSV and Import to Staged need seller Level 4. The $1.49 shipping minimum applies only under a $5.00 product total.
- **Nothing is built against a channel.** `#/codes` exports a list of codes and sends nothing.
