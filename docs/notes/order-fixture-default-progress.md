- order-fixture-default-progress: `order()` in `app/tests/routeFixtures.ts` sets `progress` to `progressOf({ wanted: 1, recorded: 0 })` by default. Its `over` argument replaces only the fields a caller passes, so a case that overrides `wanted` or `recorded` keeps a row that says one wanted, none recorded. Cases that state totals should also pass `progress: progressOf(...)`, the helper defined beside `order`.
