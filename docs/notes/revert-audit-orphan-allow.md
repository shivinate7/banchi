- revert-audit-orphan-allow: `guard()` in `scripts/revert-audit.py` passes a head that shares no history with upstream (`git merge-base` exits 1, empty stderr), because the orphan record branch never becomes a PR. A merge of unrelated histories can still rewrite a path both sides add (add/add), so a PR head with no shared history would pass unread. Nothing opens such a PR in normal work; if one does, the pass line is the only sign.
