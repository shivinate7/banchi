- revert-audit-orphan-allow: `guard()` in `scripts/revert-audit.py` passes a head with no shared history (`git merge-base` exits 1, empty stderr, full clone only) because the guard judges what a branch would land against main's revert history, and none is shared with main, so there is nothing to revert. The pass reads no file contents: a merge of unrelated histories can still rewrite a path both sides add (add/add), so a PR head with no shared history would pass unread. Nothing opens such a PR in normal work; if one does, the pass line is the only sign.
