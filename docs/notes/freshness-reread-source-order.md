- freshness-reread-source-order: On `origin/lane/orders-reread` (PR 1137, not on main), recogniser 14 (`write through the after-write helper`) in `scripts/screen-freshness.mjs` counts a `rereadNow` call as covering a write when the call starts later in the handler's text (`getStart() >= writeAt`). It ignores control flow, so a `rereadNow` in the else branch of the write's own `if` passes a write that is never followed by a re-read. It bites when a screen writes on one branch and re-reads only on the other.
