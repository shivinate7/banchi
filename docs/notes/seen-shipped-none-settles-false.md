- seen-shipped-none-settles-false: `_seen_shipped` sets a None flag to False on any pre-ship read, even when the stored status already reads as shipped. A legacy order held at a shipped status, then re-read at Ready to Ship, reads as never shipped. `Ledger.never_shipped` then lets its canceled order's sale undo, as the Sale on Orders row of `docs/specs/undo.md` allows, so the sale undoes for an order that may have shipped. No test feeds a None at a shipped status. It bites on the first feed read that goes back to a pre-ship word.
