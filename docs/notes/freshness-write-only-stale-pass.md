- freshness-write-only-stale-pass: On `origin/lane/orders-reread` (PR 1137, not on main), recogniser 7 (`write-only field: nothing on screen renders it`) in `scripts/screen-freshness.mjs` passes a write when none of its payload keys is read on the screen (`fieldIsRead`). A write can change a value the screen does render, such as a count the server recomputes, while its own arguments stay unrendered, and that stale write passes. It bites on a write whose effect reaches the screen through the server rather than through its own fields.
