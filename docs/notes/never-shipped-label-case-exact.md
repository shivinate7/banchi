- never-shipped-label-case-exact: `Ledger.never_shipped` tests `record.number in self.labels`, an exact string match. `Ledger.claim_label` keys a label by the order string it gets, and `fold_number` folds case only for the name-by-number match. An order whose label was claimed under a differently cased number reads as never shipped, so a made label can be missed. It bites when a label's order number and the feed's number differ only in case.
