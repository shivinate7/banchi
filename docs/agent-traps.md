# Agent traps

Tool and test traps that produced a false green or a lost tree in this repo.

## A guard can pass for the wrong reason

- **The fixture never drew the control under test.** A case guarded on `if (await bar.count())` never ran its assertion, because the seeded store never rendered the bar. Assert that the control exists before asserting on it.
- **A probe that reads only the fold tests only the first screenful.** `elementFromPoint` answers about the current viewport. Scroll before you sample.
- **The client under the assertion can discard the evidence.** `http.client` zeroes a HEAD response's body before a byte is read, so `checks.equal(body, b"")` passed against a server that wrote a full body. Read raw bytes off the socket when the claim is about the wire.
- **A decoy built from a typed-in literal survives the mutation it exists to catch.** Build the decoy with the same generating function the real code uses.
- **A per-run fixture that treats a machine-wide resource as private races other sessions.** A fixed process name found through `pgrep -f`, or a "free" port found by probing a range, can collide. Then the guard correctly refuses. Use a `<role>-<mktemp>-<pid>` name, bind port 0 and read it back. Add no lock. `pgrep -fc` is not a count on BSD, so count with `pgrep -f ... | wc -l`.
- **A citation probe that tokenizes the citation scores hits off the subject's own filename.** A path naming `join` matches "join" on almost any line of that module. Exclude tokens derived from the subject's own path and stem. Report "names no real identifier" as not checkable.
- **A Playwright geometry sweep that is green locally and red on CI is usually a sampling artifact.** Scan every whole-pixel scroll offset. One consecutive failing band shows that a sticky or fixed ancestor covers the control at that stop. A sweep with large steps can sample a long page at two points and mistake a wide band for a flake.
- **A request timeline alone turns a theory into false certainty.** Decode the fulfilled response bodies in the trace's `test.trace` JSONL (the `before` events) first. Playwright's array-failure output is a diff, not a positional list: `-` is expected only, `+` is received only.
- **A test that mutates its own stub after `click()` races the browser.** `click()` resolves on dispatch and does not wait for the re-read. Move the mutation into the write route's handler, after the row's fetch and before the re-read. A `waitForTimeout(300)` between click and mutation turns the latent race into a deterministic red, for diagnosis only. See DEBT23.
- **Four mutation arms can go green over one row for three unrelated reasons.** The row may be the walk's current row, the one just sold, or the one the ranking froze. Aim a fold or freeze case at a mid-list row that is none of those.
- **A mutation run owns the whole working tree.** Do not commit, stash, check out or edit while one is in flight. A stash once fired mid-run. A background Playwright run then restored a mutated file and reported a false pass, because one dev server serves all of `app/src`.
- **A dry-run guard built from a deny-list of guessed endpoint names fails open.** It let a real 100-row Staged import through, because the real endpoint names matched no guess. Invert it: block every non-GET, allow only calls already observed and judged safe, and drive one harmless write through it to prove it fires.

## Session and worktree traps

- **The Browser pane does not repaint while hidden.** Scrolling returns a blank screenshot or times out. Grow the viewport with `resize_window` to hold the whole document (read `document.documentElement.scrollHeight` first). `zoom` with a `region` returns the full screenshot, so magnify the element in place with `javascript_tool`. Do not mix screenshot-frame pixel coordinates with a `ref` click's full-resolution coordinates.
- **A theme cross-fade makes a mid-transition screenshot lie.** Wait 3 to 5 seconds after a theme change. Set the theme through `localStorage` and reload, because writing `data-theme` leaves React's state stale.
- **`preview_start` inside a worktree can serve the main checkout.** It runs from the session's launch directory, so `app/` resolves against the main tree and binds the main checkout's port. The tell: `curl -s localhost:<port>/src/<edited file>.ts | grep <new symbol>` finds nothing. Prefer `make dev` over Bash from the worktree. A subagent's `preview_start` can return the orchestrator's server with no PID. Brief a subagent to use `make dev`, and to report id, port and cwd before it stops anything.
- **Message a live peer before commenting on its PR.** `ListAgents` and `SendMessage` reach a session in seconds. A PR comment waits for a human and can land after the merge. Fall back to a comment only when no worktree holds the branch.
- **Before you report work lost, look for a branch that holds it.** A clean tree after a peer moves `HEAD` usually shows work committed elsewhere. Run `git branch -a --contains <sha>` or `git log --all --oneline -- <path>`.
- **A command's byte count is not its token cost.** The Bash tool persists large output to a file and shows about 2 KB of its first bytes. Probe a known size before you infer cost, and print the verdict first.
- **`make janitor ARGS=--confirm` (claude-settings' sweep) and `scripts/janitor.py --confirm` treat a hand-made worktree as abandoned.** Its liveness oracle is the home directory's Claude session registry, and `git worktree add` registers nowhere. Read the whole preview, never `tail` it. Do not confirm while a hand-made worktree is in use. Use the Agent tool for worker worktrees so they register.
- **An isolated agent's worktree can vanish under a resumed session.** `isolation: 'worktree'` cleans a tree it judges unchanged, even under a resumed agent or one that already pushed. Then `git` in that path resolves to the primary checkout, and a write can land there and switch its branch. Stand the dead agent down and spawn a fresh isolated agent on the pushed branch. Give every reviewer `isolation: 'worktree'` too.
- **A subagent-model override in `.claude/settings.local.json` cannot be cleared from inside the running session.** Claude Code rewrites the file from memory and the keys reappear, and the classifier refuses the edit as self-modification. Ask the person to drop the keys. Or use `PKMNSCAN_DOCS=off` on the one commit that needs the `subagent override` row skipped.
- **A session-level STE lint hook on Write and Edit lints the whole resulting file.** If the file already carries error findings anywhere, every edit is refused with line numbers the edit never touched. Lint your snippet alone with `python3 scripts/ste/ste_lint.py <tmpfile>`. Ask before you route around the hook with a heredoc.
