The queue list · the sort has to be visible without reading a number

store/queues.py's sort_key puts priced cards first, descending, then unpriced, then box-walk order. Name size and price size step down with the price; a parked row is dimmed rather than merely lower. Photo-led rows, no column rules — this is the answer to being a list of hundreds of rows without becoming a spreadsheet.
